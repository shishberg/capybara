# v3 sources from Rosebear

This is not a design version. It is the part of Rosebear's v3 board generator that the paused seeded-board pipeline (`make build`) still runs. Rosebear's `v3/README.md` and its design notes, such as `v2-p4-pod.md`, explain the design behind it; they stay in the [Rosebear repo](https://github.com/shishberg/rosebear).

## What's here

- `baml_src/`: the generator, about 13,000 lines of BAML. From the 36-key layout it places the keys, cuts flat flex boards to wrap a Dactyl Manuform key well, builds the diode-matrix netlist, the FFC ribbons and the ESP32-P4 pod board, routes the copper and writes `.kicad_pcb` files.
  - Layout: `geometry`, `layout`, `config_rosebear`, `config_dactyl`, `features`.
  - Boards: `well`, `flex`, `flex_board`, `thumb`, `panel`.
  - Wiring: `netlist`, `matrix`, `ribbon`, `pod`.
  - Copper: `route`, `route_matrix`, `route_thumb`.
  - Output: `emit`, `build`.
  - `*_test.baml`: v3's own tests. Nothing here runs them.
- `baml.toml`: the BAML project file.
- `footprints/rosebear.pretty`: Kailh MX hotswap footprints, 1u to 2.75u, generated by `footprints/gen_hotswap.py`.

## How the pipeline uses it

`rosebear/seed.py` copies these files and `tools/seed.baml` into `output/geometry/`. It then patches five values in the copy, never here:

- the key well, from `mechanical/chassis.json`;
- the flex tail, 5 mm;
- the diode reach, 8.2 mm;
- the pod pin map, from `pod.json`;
- one routing turn.

It then runs `seed_export`. That writes:

- `output/geometry.json`: the finger keys, strips, cuts, neck and thumb-fan copper, wire feet, the well and the pod pinout;
- seed boards, in `output/geometry/seed/`.

`tools/build.py` turns these into the finger boards and pod in `output/seeded/`. `rosebear/pcb.py` also loads the hotswap footprints from here.

## What still depends on it

The key-tile build, `tools/build_key_quotes.py`, makes its pod from `output/seeded/pod.kicad_pcb`. It copies the module header, ribbon connectors, buttons and mounting holes, so the current pod board still comes through v3. The editor and the chassis build don't use v3.

This directory can go once the key-tile pod is built without the seeded pod and the paused pipeline is dropped.
